# Agent Note: 无标题会话渲染为带日期的新会话行

Status: implemented

[English](2026-08-24-untitled-sessions-dated-label.md) | 中文

## 问题

会话行存储的显示标题来自 client 运行时的投影：先是持久化标题，其次是会话 cwd 的 basename，最后是原始会话 id。没有持久化标题的会话——早于标题服务存在的日志，或标题投影尚未到达的行——以其所在 workspace 的目录作为 cwd，因此同一 workspace 分组下的每个无标题行都渲染成了 workspace 自己的名称。某个分组曾显示五行完全相同的行，全部读作分组标签，彼此无法区分，且都被误标为 workspace 本身。

## 决策

workspace 树会把摘要中没有持久化标题的非空会话行标记为 `untitled`（`SessionNode.untitled`，由 `SessionSummary.title === undefined` 推导）。行渲染器沿用既有的空行替换模式：不渲染存储的标题——此状态下它只是目录 basename 回退——而是渲染带日期的新会话标签（`session.untitled`，中文为「新会话 · 2026年8月24日 09:32」），时间取会话的最近活动时间，经由字典的日期模板格式化。该标签是有含义的（一个未命名会话），并且如实表明它不是标题。由于时间戳只精确到分钟，推导层会为同一分钟冲突集合的每个成员编号（`SessionNode.untitledNumber`，按渲染列表内的行序分配；`session.untitledNumbered`，中文为「新会话 · 2026年8月24日 09:32（2）」），因此同一列表中的两个无标题会话永远不会渲染出相同的文本。一旦 Host 投影出持久化标题，同样的行会原样渲染该标题——包括确实与目录同名的持久化标题，它永远不会进入无标题路径；搜索和复制功能继续读取存储的标题，其余行为不变。

运行时投影本身保持不变：`displayTitleOf` 是仓库范围内唯一的名字推导，会话头部和 subagent 谱系也在使用，在那些界面中 basename 仍是合理的最终回退。

## 备选方案

**修改运行时回退链以跳过 cwd basename。** basename 一级是经过斟酌并写入文档的决策，被所有为会话命名的界面共享，包括会话头部；移除它会改动从未被报告异常的界面，并且侧边栏各行依然无法区分（id 回退同样没有意义）。

**回退到会话的首条用户消息。** 会话摘要不携带消息内容；在对象层合成摘要会重复 Host 标题服务的回退逻辑——该服务本来就会把它折叠过的会话的首条消息标题写成持久化事件。

**以原始会话 id 作为标签。** 虽然可区分，但可读性差，并且会把内部标识符当成标题展示。

## 影响

- 同一分组下的无标题行彼此可辨，也与组头可辨，任何一行都不会再冒充 workspace；同一分钟的冲突会带上序号，因此可区分性保证没有缺口。
- `SessionNode` 新增可选的 `untitled` 与 `untitledNumber` 字段（缺省为 false／不编号），现有构造点不受影响；无冲突的列表保持各行标识不变（推导层原样返回输入数组）。

## 测试

`tree.client.spec.ts` 覆盖该标志的推导（无标题、有标题与空行）以及分组、扁平与保留行集合中的冲突编号。`rows.client.spec.tsx` 覆盖无标题行渲染带日期标签——冲突时带序号——而有标题行渲染其存储标题。`workspace-browser.client.spec.tsx` 覆盖组装后的回归：缺少持久化标题的分组渲染非空且两两不同的标签，workspace 名称只出现一次；当同样的行获得持久化标题后，即恢复显示真实标题，包括确实与目录同名的标题。
