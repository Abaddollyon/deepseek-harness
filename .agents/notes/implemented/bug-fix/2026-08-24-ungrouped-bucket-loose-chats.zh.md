# Agent Note: 未分组桶命名为游离会话

Status: implemented

[English](2026-08-24-ungrouped-bucket-loose-chats.md) | 中文

## 问题

不属于任何 workspace 的会话会归入侧边栏一个原本只标注为「未分组」（Ungrouped）的桶。这个光秃秃的形容词说的是这些行缺少什么，而不是它们是什么；用户会把这个桶读成管理性的残留区域，而不是他们游离会话的归宿。文案必须明确说出「会话」：这些只是没有 workspace 的对话。

## 决策

`group.ungrouped` 字典条目现在为英文「Ungrouped chats」、中文「未分组会话」。树推导中的 `UNGROUPED_LABEL`——供搜索标签和无 cwd 界面使用的非本地化回退——与英文条目保持逐字一致，并由一条 tree 测试断言两者永不漂移。删除 workspace 对话框的描述文案（`delete.desc`）在两种语言中使用同一标签；所有按旧文案精确匹配的端到端选择器与回放快照也已同步更新。

## 备选方案

**保持「未分组」。** 这正是被用户反馈为含义不清的文案；保持原样等于没有回应。

**改为「无 workspace」。** 它描述的是缺失而不是内容；一个装会话的桶应当说明里面装的是会话。而且它读起来像错误状态，而不是正常的存放位置。

**只改渲染层标签而保留 `UNGROUPED_LABEL` 为「Ungrouped」。** 这样搜索结果和无 cwd 的回退界面会对同一个桶显示不同的名字，重新制造本次改动要消除的不一致。

## 影响

- 该桶在两种发布语言中都读作游离会话的集合，删除对话框中「其会话将显示在……下」的表述保持准确。
- `UNGROUPED_LABEL` 与字典由测试锁定一致，今后的文案改动必须同时更新两处，否则测试失败。
- 英文回放快照与 e2e 选择器已随文案迁移；不再有任何地方依赖旧标签。

## 测试

`rows.client.spec.tsx` 断言该桶渲染中文字典标签，而绝不渲染推导层存储的英文标签。`tree.client.spec.ts` 断言 `UNGROUPED_LABEL === en['group.ungrouped']`。组装后的浏览器测试中未分组桶流程与删除对话框断言均已同步为新文案。
