# Agent Note: 自动发现提供方模型

Status: implemented

[English](2026-09-04-automatic-model-discovery.md) | 中文

## 问题

提供方发布模型可能早于已安装 pi-ai 目录的更新。静态配置因此会让 LLM（大语言模型）服务的全部消费方看不到新模型，而独立的选择器目录又可能显示请求发送时无法解析的模型。

## 决策

[pi-ai 适配器](../../../../packages/llm/llm-pi-ai/README.zh.md)负责显式启用的认证发现操作和共享不可变有效目录。显式模型条目和覆盖项优先于规范化实时元数据，后者优先于已安装容量和已公布能力；同一 id 的已安装模型仍提供协议兼容性。未知 id 使用配置路由的协议与保守容量／模态默认值。发现操作既不编辑设置，也不选择模型。

每条路由拥有一次刷新、取消控制器、定时器以及按配置／凭据限定的元数据缓存。启动时先恢复可用磁盘元数据，再执行网络发现。凭据通知阻止陈旧请求发布；刷新自身串行 `Models.getAuth` 操作中的 OAuth 轮换会继续使用新授权。其他账户变更仍会使请求失效。元数据提交后，发布操作替换适配器注册，复用 `llm/adapters-updated` 及其隔离观察方错误的分发机制。已捕获请求快照保持不可变。缓存身份包含提供方解析后的 API 密钥认证，以及解析期间查询的凭据引用，因此环境密钥轮换不会恢复其他账户的模型。OAuth 缓存身份读取已存授权而不刷新它。整个操作的期限约束每个等待阶段，并阻止迟到的只读结果发布。缓存写入使用私有暂存文件和串行提交；dispose（资源释放）等待已启动的文件系统写入，但脱离不可取消的只读依赖。已启动的原生文件系统操作无法强制取消。

已知模型操作立即捕获快照。已启用路由遇到未知 ID 时，先等待缓存恢复；若仍缺失，再等待有期限的共享刷新。调用方可取消等待；已恢复的 ID 不依赖网络请求结束。就绪后才捕获不可变的发送快照。可选凭据服务就绪时会使先前的启动认证读取失效，避免真实 Loader 启动顺序导致冷进程无法使用其账户缓存。

Codex 元数据使用公开官方 npm 包端点公布的当前稳定版本进行协商。公开请求不携带提供方认证、不允许重定向，并且只消耗刷新期限中的有限部分。查询失败时可继续使用已缓存的成功版本。元数据协商不改变 pi-ai 执行标头，也不证明新公布模型的兼容性。只有允许的规范化字段会被保留；提供方提示词、指令和未知字段均被丢弃。经过验证的否定可选资格与能力分别保留，避免已安装回退项和上次有效元数据让隐藏／内部或显式不受支持的选项重新出现。显式条目／覆盖项仍具有权威性；已保存选择保留其请求发送描述符。省略的行保留原状态，有效的正向行清除排除项。元数据与排除项共享账户／配置隔离、持久恢复、已验证续期迁移和总量限制。

Models 设置编辑器公开逐路由自动发现开关，同时保留显式模型条目与未知配置字段。其手动**获取可用模型**控件仍是独立的草稿／采纳流程。浏览器模型选择器共用一份目录，会合并打开陈旧目录时的重验与显式刷新，在部分失败时保留上次成功的行，并保住所选路由。Composer 增加紧凑的提供方／模型搜索和低调的刷新操作，但不改变 Model→Effort 导航；`/model` 使用命令外壳的搜索来浏览同一份已刷新目录。委派继续使用独立的暂存目录，在凭据、适配器、设置、重连与打开陈旧目录信号后刷新，并保留草稿和不可用的已配置行。

## 考虑过的替代方案

仅用于续期的共享认证注入在串行提供方刷新事务中观察前驱和后继授权，再核对已提交后继。它服务于发现、生成请求即时认证和强制恢复，但不用于登录。仅当前驱与当前缓存身份匹配时才保留元数据和 Codex 版本。迁移会把规范化数据写入后继指纹名下；逐路由写入序列防止迟到迁移覆盖更新的目录提交。未被观察到的外部替换仍视为失效，不推断为同账户续期。缓存迁移错误不使生成认证失效，发现操作仍可重试。

**刷新时重写模型配置。** 不采用，因为发现操作会覆盖显式选择，并将临时提供方回复变成用户设置。

**维护选择器专用目录。** 不采用，因为聊天、委派、自动化和远程配置必须通过同一请求发送服务解析模型。

**永久固定 Codex 发现版本。** 不采用，因为服务端版本过滤可能在认证成功时仍隐藏新模型。公开版本协商使发现结果保持更新，代价是需要单独验证提供方执行能力。

## 后果

离线缓存、选择器上次成功的行与逐路由失败隔离保留可用性。元数据不是模型执行 canary；未知协议行为仍需通过无害的真实提供方请求验证。已安装和显式模型仍是有用的回退项，未知推理支持保持保守。可选缓存具有版本，仅属主可访问，不存储凭据或远程指令正文。针对性测试覆盖真实 Loader 组合、可选模型与可发送模型一致性、覆盖项、OAuth 刷新、并发合并、取消、周期任务、陈旧账户请求隔离、离线恢复、协议分页／限制、秘密信息剔除、选择器搜索与键盘行为、设置字段保留，以及委派草稿保留。
