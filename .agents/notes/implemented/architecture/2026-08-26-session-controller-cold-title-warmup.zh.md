# Agent Note：Session Controller 冷标题预热

状态：已实现

[English](2026-08-26-session-controller-cold-title-warmup.md) | 中文

## 问题

持久化会话列表曾等待冷数据工作，且未附加 Session 的行没有持久化标题路径。

## 决策

ApiSessionList 保留仅覆盖当前可见冷行、并以 createdAt 与 cwd 为键的标题缓存。列表会立即返回，并启动非阻塞的分批 sessionQuery.readTitleSnapshots。成功快照由后续轮询使用；失败或中止的批次保持可重试，批次条目身份检查、实时会话检查和销毁清理会阻止过期结果发布。实时行会使其冷标题失效，因此后续转为冷行时会刷新持久化标题。

## 后果

冷列表保持仅元数据读取，标题读取按批次执行，而标题可见性会在后续轮询中最终一致。缓存裁剪会阻止已消失记录保留标题状态。

## 备选方案

打开完整 Agent 或等待标题读取会违反冷列表延迟和不激活保证。
