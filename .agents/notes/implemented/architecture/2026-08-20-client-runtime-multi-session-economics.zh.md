# Agent Note: What the browser pays per session it is not looking at

Status: implemented

[English](2026-08-20-client-runtime-multi-session-economics.md) | 中文

## 问题

对象层向主机上的每个会话收费，而不是只向屏幕上显示的会话收费。

每次投影写入都会同步调用 `markDirty`，因此投影风暴会针对每个投影发布一次消费者更新，而不是每帧发布一次。无论是否有人能看到，每个会话的 `session/event` 都会被折叠进其对话：当多个会话同时流式传输时，标签页要为无人查看的窗口支付折叠、快照重建和 React 工作的成本。

从未释放任何内容。子代理目录和每个会话的派生状态会在整个标签页生命周期内累积。列表快照会整体重建其记录映射（对整个世界执行 `Object.fromEntries`），因此每次列表变化都会使每一行输入的身份失效，并让侧边栏整体重新渲染。

冷启动被不必要的证据读取串行阻塞：首次绘制要等待它本可推断出的读取结果，而且每次打开都会重新获取空的子代理目录。

连接的帧收件箱使用 `shift()` 出队，因此队列突发会呈二次退化，恰好发生在突发最大的时候——重连和首次加载时。

## 决策

**每帧发布一次流式状态。** 投影存储的 `subscribeAny` 和 jobs 路径都经过 `notifier.markFrameDirty`，其 rAF 批处理会把风暴压缩为一次发布；投影路径现在只应用存储。一项测试驱动相当于 100 帧的写入，并断言只发送一次通知。

**只折叠正在观察的内容。** 选择会话会暂停之前的会话并恢复所选会话；非活动会话的 `session/event` 会暂停，并返回折叠前的状态，而不是执行折叠。`Session.conversationStale` 记录其窗口已经落后，恢复时通过已有的尾部重新拉取路径重新同步，而不是重放——这是有意设计的，因此用户刚返回的会话不会在界面上显示加载闪烁。重连只重新同步所选会话。

**释放不再活动的内容。** `pruneRetainedState` 遍历活动集合和受保护集合，`catalogAccess` 时钟将保留的子代理目录限制在 `MAX_RETAINED_CATALOGS = 128`；基线落地后执行清理。

**保持列表身份稳定。** `stableRecordMirror` 和缓存的记录镜像会在未触及某一行的变化中同时保留映射和快照身份，因此侧边栏的记忆化行会保留其输入。

**解耦冷启动，并快捷处理已知为空的情况。** `freshEmpty`/`nonEmptyEvidence` 集合驱动 `knownEmpty` 快捷路径，因此 `refreshSubagentsForOpen` 只跳过已证实为空的目录；来自列表、订阅、事件和状态的证据会使其失效，而断开连接会清除它。

记录中还包含两项修正，因为这两项都是这类优化容易引入的错误：

- **投影基线不能作为种子。** 部分列表块只应用它提供的键，因此缺失的键不会清除已有值，过时的块也不能覆盖更新的块。`knownEmpty` 只快捷处理*目录*——`Session.open` 仍会获取历史，因此不会跳过图像限制等值。
- **必须允许重新加载获胜。** 当会话阶段仍为 pending 且目标工作区已有成员关系时，`startInitialSelection` 会等待，因为代码所述：“非空的工作区成员关系表明可能存在可恢复的会话；在允许创建之前等待其行。”没有这个保护，快捷路径会与重新加载竞争，并在可恢复的会话之上创建新会话。

**帧收件箱改用带索引的双端队列，**使用头部索引和阈值压缩替代 `shift()`。

## 备选方案

**在恢复时重放非活动会话的缓冲事件。** 拒绝：在唯一重要的情况下（长时间离开），缓冲区没有上限；尾部重新拉取是一次有界请求，还能修复离开期间产生的任何间隙。

**从列表块为缺失的投影键设定种子。** 明确在代码中拒绝：把部分块当作完整种子会让较旧的响应清除较新的值，这是披着优化外衣的数据丢失错误。

**在出现重新加载竞争后移除 `knownEmpty` 快捷路径。** 拒绝：竞争发生在选择时序中，而不在快捷路径中；保护逻辑命名了它要等待的证据，而不是增加延迟。

## 影响

现在每帧成本与屏幕上的会话成正比。非活动会话的界面在恢复前会保持过时——这是可接受的，因为它没有被渲染，并会在恢复时重新同步解决。保留目录数限制为 128，但受保护和正在处理的条目可能会在短时间内使数量超过目标。rAF 批处理意味着消费者现在以帧频而不是每次写入看到流式状态，这是 `markFrameDirty` 的预期契约，并由测试直接断言。
